# TYPE BIT

TYPE BIT is a desktop typing practice and tutor app with a live typing speed meter widget. Supports English and Bangla, with more languages coming soon.

## Development Setup

```bash
git clone https://github.com/pickatoz/type-bit.git
cd type-bit
pnpm install
pnpm tauri dev
```
